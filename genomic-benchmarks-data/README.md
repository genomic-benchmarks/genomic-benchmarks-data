# genomic-benchmarks-data

`genomic-benchmarks-data` provides access to curated genomic benchmark
datasets, including all published splits and `test` data. For a comparison of
the two packages and the complete shared API, see the
[project README](https://github.com/genomic-benchmarks/genomic-benchmarks-data).

## Install

```bash
python -m pip install genomic-benchmarks-data
```

Python 3.12 or later is required. Import the package as
`genomic_benchmarks_data`.

## Tutorial

See the
[full-package tutorial](https://github.com/genomic-benchmarks/genomic-benchmarks-data/blob/main/tutorials/genomic-benchmarks-data.ipynb)
for a step-by-step workflow covering discovery, metadata, loading, caching, and
quality control.

## Package-specific behavior

This package exposes every published split, including `test` and
`test_leftout` where supplied by a benchmark.

By default, `load_dataset()` selects the sequence and label columns. For
`test` and `test_leftout`, it also puts `id` and `row_index` first. The stable
`id` links predictions and evaluation results back to exact `test` examples,
while `row_index` preserves their original order. Pass `columns="all"` to load
every column in its original order.

The cache is in the operating system's standard user cache directory. On
Linux it is `~/.cache/genomic_benchmarks_data`. Download functions return the
exact cached paths.

## Package-specific QC

The package provides class QC for available splits and split QC between
available split pairs. Results and self-contained reports are generated by
[`genomic-benchmarks-qc`](https://github.com/genomic-benchmarks/genomic-benchmarks-qc)
and distributed in the
[`genomic-benchmarks-data` QC Zenodo record](https://zenodo.org/records/23324188),
which contains further provenance and artifact details.
