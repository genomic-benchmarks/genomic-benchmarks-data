# genomic-benchmarks-data4agents

`genomic-benchmarks-data4agents` provides agent-safe access to curated genomic
benchmark datasets. It exposes training data and its class quality-control
results without exposing held-out data or split-QC information. For an
overview and quick start, see the
[project README](https://github.com/genomic-benchmarks/genomic-benchmarks-data).

## Install

```bash
python -m pip install genomic-benchmarks-data4agents
```

Python 3.12 or later is required. Import the package as
`genomic_benchmarks_data4agents`.

## Public API

Dataset discovery and access:

- `load_metadata()` returns the complete packaged metadata;
- `list_collections()` and `list_datasets()` discover available data;
- `list_molecular_levels()`, `list_task_categories()`, `list_task_types()`,
  and `list_species()` list metadata values within a collection;
- `get_dataset_info()` and `get_split_info()` inspect metadata;
- `download_dataset()` downloads a training split and returns its cached path;
- `load_dataset()` returns a training split as a pandas DataFrame.

Downloaded tables begin with the stable `id` and zero-based `row_index`
columns. Their remaining columns are dataset-specific.

The cache is in the operating system's standard user cache directory. On
Linux it is `~/.cache/genomic_benchmarks_data4agents`. The download functions
return the exact cached paths.

## Quality control

Class QC is available by passing `"class"` as `qc_type` to:

- `download_qc_csv()`;
- `load_qc_results()`;
- `list_qc_metrics()`;
- `filter_datasets_by_qc()`; and
- `plot_qc_summary()`.

QC outcomes use the flags `Pass`, `Warning`, `Fail`, and `Unknown`.
Filtering and plotting can consider all checks or a selected check.

`get_class_qc_report()` retrieves a self-contained HTML class report for a
training split. This package does not provide split QC or
`get_split_qc_report()`.

The QC results are generated by
[`genomic-benchmarks-qc`](https://github.com/genomic-benchmarks/genomic-benchmarks-qc).
The agents-package Zenodo QC record will be linked here when it is available.
